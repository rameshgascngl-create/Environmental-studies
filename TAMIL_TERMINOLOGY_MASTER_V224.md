# Environmental Studies v2.2.4 — Tamil Naturalisation & Terminology Master

## Governing rule
Preserve established Tamil Nadu textbook scientific terminology, but choose grammar from the scientific meaning rather than from an English source-word. A single English adjective such as “related” must not force a single Tamil equivalent everywhere.

## Context-sensitive relationship language

| Intended meaning | Preferred Tamil |
|---|---|
| depends on / is dependent on | **சார்ந்துள்ளது / சார்ந்து / ஒன்றையொன்று சார்ந்து** |
| interacts / functions together | **இணைந்து செயல்படுகிறது / ஒன்றுடன் ஒன்று இணைந்து** |
| about / regarding a topic | **பற்றிய / குறித்து** |
| applicable to a law/rule | **பொருந்தும்** |
| associated factors without causal claim | **இணைந்த காரணிகள் / இணைந்து காணப்படுகின்றன** |
| established causal mechanism | State the causal pathway explicitly |
| ecological/feeding interaction | **தொடர்பு** may be retained |
| communication | **தகவல் தொடர்பு** retained |
| human–wildlife interaction | **மனித–வனவிலங்கு தொடர்பு** retained |

## Canonical scientific terms reaffirmed
- Environment — **சுற்றுச்சூழல்**
- Ecology — **சூழலியல்**
- Ecosystem — **சூழ்நிலை மண்டலம்**
- Biodiversity — **உயிரிய பல்வகைத்தன்மை**
- In-situ conservation — **சூழல் உள் பாதுகாப்பு**
- Ex-situ conservation — **சூழல் வெளிப் பாதுகாப்பு**
- Eutrophication — **மிகை உணவூட்டம் (Eutrophication)**
- Greenhouse effect — **பசுமைக்குடில் விளைவு**
- Greenhouse gas — **பசுமைக்குடில் வாயு**
- Climate mitigation — **தணித்தல்**
- Adaptation — **தழுவல்**
- Resilience — **மீள்தன்மை**
- Hazard — **இடர்**
- Risk — **அபாயம்**
- Emission — **உமிழ்வு**
- Biomedical waste — **உயிரிமருத்துவக் கழிவு**
- Environmental Impact Assessment — **சுற்றுச்சூழல் தாக்க மதிப்பீடு**

## Review-writing rule
Unit-review questions should be generated from the canonical Tamil lesson title:
`<பாடத் தலைப்பு> என்ற தலைப்பின் முக்கியக் கருத்துகளை...`
This prevents repetitive and grammatically weak `... தொடர்பான முக்கியக் கருத்துகள்` constructions.

## Controlled scope
This master governs the v2.2.4 Tamil language layer only. It does not authorise changes to English lessons, syllabus coverage, lesson order, Android logic, figures, privacy behaviour or permissions.
